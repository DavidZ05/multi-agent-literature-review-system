# v0.8.1

v0.8.1 makes the project easier to evaluate and adopt without changing the
runtime workflow contracts introduced in v0.8.0.

## Added

- Public documentation site built with MkDocs Material.
- GitHub Pages build and deployment workflow with strict documentation checks.
- English product and operations documentation plus a Chinese quick-start page.
- A privacy-safe Workbench overview captured from deterministic test data.
- Automated tests for the public site contract and secret/path hygiene.

## Fixed

- Invalid Review Synthesizer API output now fails with the documented
  `invalid_agent_output` error when revision has no concrete `must_fix` item.

## Runtime compatibility

Workflow stages, SQLite schema, CLI commands, artifact formats, provider
contracts, and agent plugin contracts are unchanged from v0.8.0.

## Requirements

- Python 3.11 or 3.12
- macOS or Linux
- Node.js 20+ only for browser development tests

See the repository [Changelog](https://github.com/DavidZ05/multi-agent-literature-review-system/blob/main/CHANGELOG.md)
for the full project history.
