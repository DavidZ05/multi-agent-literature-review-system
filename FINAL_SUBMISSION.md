# Final Submission Guide

## Project

**Memory-Augmented LLM Agents: Mechanisms, Evaluation, and Reliability in Multi-Agent Systems**

This folder contains a runnable multi-agent literature review system and the survey generated by that system. The system uses a verified literature corpus, agent role prompts, an orchestrated Search-Writer-Expert Review-Polish-Final Verification workflow, and automatic citation-key checking to reduce hallucinated references.

## What to Submit

## How to Run

From this folder:

```bash
python3 -m src.memory_review_pipeline
```

Expected result:

```json
{
  "status": "accepted",
  "survey": ".../outputs/survey.md",
  "review_report": ".../outputs/review_report.json",
  "final_verification": ".../outputs/final_verification.json",
  "evaluation_report": ".../outputs/evaluation_report.json"
}
```

## Output Files

- `outputs/survey.md`: the generated survey report.
- `outputs/review_report.json`: Expert Review Panel and synthesized revision result.
- `outputs/final_verification.json`: post-polish citation and integrity check.
- `outputs/evaluation_report.json`: Evaluation / Reflection Agent scoring output.
- `outputs/reflection_log.md`: readable reflection on agent performance and next improvements.
- `outputs/runtime_config.json`: sanitized runtime backend configuration for the run.
- `outputs/revision_log.json`: revision-loop trace.
- `outputs/intermediate/search_report.json`: Search Agent handoff.
- `outputs/intermediate/writer_draft.md`: accepted Writer Agent draft before final polish.
- `outputs/intermediate/citation_audit.json`: Citation Auditor result.
- `outputs/intermediate/domain_review.json`: Domain Expert result.
- `outputs/intermediate/structure_review.json`: Structure Mentor result.
- `outputs/intermediate/revision_plan.json`: Review Synthesizer result.

## Design Highlights

- Search Agent groups verified papers from `data/papers.json`.
- Writer Agent drafts the survey using only verified citation keys.
- Expert Review Panel checks citation integrity, topical coverage, and structure.
- Review Synthesizer passes blocking feedback back to Writer.
- Polish Agent cleans accepted Markdown without adding new claims.
- Final Verification Reviewer checks the polished draft before final output.
- Orchestrator coordinates the workflow and stops when Review Synthesizer returns `accepted` or the loop limit is reached.
- `.env.example` documents optional single-API and multi-agent API configuration; local deterministic execution is the default.

## Human Intervention Points

Human intervention is placed at high-impact decisions:

1. choosing the topic and research question;
2. approving the seed corpus;
3. resolving citation-risk warnings;
4. judging final survey quality;
5. checking files before submission.

This keeps the system automated by default while preserving human responsibility for academic judgment.
